
/Propósito de la aplicación Web/

SoloTenisRD es una plataforma web diseñada para la venta y promoción de tenis deportivos y casuales en la República Dominicana.
El objetivo principal del sitio es ofrecer a los usuarios una experiencia sencilla, atractiva e intuitiva para explorar diferentes modelos de calzado, 
conocer sus características y precios, y registrarse como clientes para futuras compras.
La aplicación está compuesta por varias páginas que cumplen funciones específicas dentro del proceso de navegación.
La página de inicio presenta una selección de tenis destacados y permite al usuario conocer rápidamente los productos más exclusivos disponibles. 
El catálogo ofrece una vista más completa de los artículos, incorporando filtros por marcas para facilitar la búsqueda de productos según las preferencias del cliente. 
Por su parte, la página de registro permite a los usuarios crear una cuenta proporcionando sus datos personales, lo que contribuye a una experiencia más personalizada y organizada dentro de la plataforma.

Este proyecto aun esta en desarrollo como parte de la asignatura de Desarrollo de Aplicaciones Web, aplicando conceptos de diseño web, estructura HTML, organización de contenido, experiencia de usuario e interactividad, con el propósito de simular el funcionamiento de una tienda virtual moderna y funcional.
